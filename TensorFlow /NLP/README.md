# 🧠 NLP Basics with Python (NLTK)

Welcome to this repository! 🚀  
This project contains beginner-friendly **Natural Language Processing (NLP)** scripts using **Python + NLTK**.

It covers the most important foundational NLP concepts:

✅ Tokenization  
✅ Text Preprocessing  
✅ Stopword Removal  
✅ POS Tagging  
✅ Named Entity Recognition  
✅ Chunking  

---

# 📂 Repository Files

| File Name | Description |
|----------|-------------|
| `basicOfNLP.py` | Basic NLP tokenization examples |
| `text_preprocessing.py` | Cleaning and preprocessing raw text |
| `remove_stopwords.py` | Stopword removal in NLP |
| `pos_tagging.py` | Part-of-Speech tagging |
| `named_entity_recognition.py` | Named Entity Recognition example |
| `named_entity_recognition1.py` | NER variation example |
| `nltk_chunking_parser.py` | Chunking and phrase parsing |
